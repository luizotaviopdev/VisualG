# VisualG

Repositório com exercícios de lógica de programação desenvolvidos em VisualG, seguindo principalmente os exercícios propostos por Gustavo Guanabara.

## Sobre

Este repositório reúne exercícios realizados durante meus estudos de lógica de programação e fundamentos de programação.

Os exercícios começam com conceitos básicos e avançam gradualmente para estruturas condicionais, estruturas de repetição, vetores, registros, procedimentos e funções.

## Conteúdos praticados

- Entrada e saída de dados
- Variáveis e operadores
- Operações matemáticas
- Estruturas condicionais
- Estruturas de repetição
- Contadores e acumuladores
- Vetores
- Registros
- Ordenação
- Procedimentos
- Funções

## Organização

Os exercícios numerados seguem uma ordem de dificuldade crescente:

| Exercícios | Conteúdo |
|---|---|
| 001–019 | Fundamentos e operações |
| 020–037 | Estruturas condicionais |
| 038–070 | Estruturas de repetição |
| 071–085 | Vetores e registros |
| 086–094 | Procedimentos |
| 095–100 | Funções |

Além dos exercícios numerados, o repositório contém outros programas desenvolvidos durante os estudos e testes de conceitos específicos.

## Objetivo

Praticar lógica de programação, desenvolver capacidade de resolução de problemas e construir uma base para o aprendizado de outras linguagens de programação.

## Referência

Os exercícios foram baseados principalmente nos conteúdos e exercícios de Gustavo Guanabara.

## Projeto

### Lista do Churrasco

Programa desenvolvido em VisualG para gerenciamento de uma lista de compras para churrasco.

O programa permite:

- Adicionar itens
- Visualizar a lista
- Alterar itens
- Remover itens
- Informar preço e quantidade
- Calcular automaticamente o valor total de cada item

O projeto utiliza vetores de registros e procedimentos para organizar as diferentes operações do programa.
